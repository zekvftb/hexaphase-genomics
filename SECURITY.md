# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in `bio-arch`, please do not open a public issue. Instead, report it directly to the project maintainers.

Please include:
- A description of the vulnerability and attack vector.
- Steps to reproduce or a minimal proof of concept.
- Affected components or input parsers.

We appreciate your responsible disclosure and effort to make open scientific software safer.
